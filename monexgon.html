Sobre el proyecto

Para MONEXGON desarrollé una identidad de marca desde cero, buscando construir una imagen vinculada al mundo financiero pero con un enfoque actual y accesible. El trabajo incluyó la creación del logotipo, la definición de una paleta cromática y un sistema tipográfico, además de los recursos gráficos utilizados para darle personalidad y coherencia a la comunicación de la marca.

Luego trasladé esta identidad al entorno digital mediante el diseño y desarrollo de su sitio web. Uno de los principales desafíos fue transformar información financiera y el funcionamiento del sistema de ahorro en una experiencia fácil de comprender, utilizando recursos visuales, jerarquías de contenido y llamados a la acción estratégicos. El sitio fue desarrollado con código y una estructura escalable, permitiendo mantener una base flexible para futuras actualizaciones, contenidos y funcionalidades.

Características principales

Brand identity

Se construyó una identidad visual sólida, moderna y reconocible, pensada para el sector financiero con un enfoque contemporáneo.

Sistema de comunicación

Se definieron recursos gráficos, paleta y tipografía para asegurar coherencia en toda la presencia de marca.

Diseño UX/UI

La experiencia digital se pensó para explicar conceptos financieros con claridad, jerarquías visuales y flujo intuitivo.

Desarrollo frontend

Se implementó un sitio con estructura escalable y adaptable, listo para mantener contenido y crecer en funcionalidades.

Mensaje financiero claro

Se transformó la información del sistema de ahorro en una narrativa comprensible y cercana para el usuario.

Call to action estratégico

Se incorporaron elementos visuales y textuales orientados a guiar al usuario hacia una acción clara y efectiva.
