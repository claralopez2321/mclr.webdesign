Sobre el proyecto

Desarrollé la identidad visual de la marca de atención médica domiciliaria, definiendo un sistema gráfico coherente y profesional. El proyecto incluyó el diseño del logotipo, la selección de la paleta cromática y las tipografías, junto con los principales criterios visuales que permiten construir una identidad cercana, clara y confiable para el ámbito de la salud.

A partir de esta identidad, diseñé y desarrollé el sitio web utilizando código y tecnologías web escalables. La interfaz fue pensada para presentar los servicios de forma clara y facilitar el contacto con los profesionales, con una estructura responsive adaptable a distintos dispositivos. Trabajé integralmente en el diseño UI/UX, la maquetación y el desarrollo frontend, creando una base flexible que permite ampliar el sitio y sumar nuevas funcionalidades a futuro.

Características principales

Atención personalizada

Se destaca la atención médica adaptada a cada paciente, con enfoque integral y cuidado clínico constante.

Cobertura por zona

La web comunica de forma clara la zona de atención, reforzando la accesibilidad y la posibilidad de asistencia en domicilio.

Desarrollo de identidad

Se definió la identidad visual de la marca a partir de una estética clara, cercana y confiable, alineada con el sector de la salud.

Diseño UI/UX

Se construyó una experiencia visual adaptable y funcional, pensada para comunicar servicios y facilitar el contacto.

Desarrollo frontend

La interfaz se desarrolló con una base escalable y responsive, lista para crecer con nuevas secciones y funcionalidades.

Contacto directo

Se incorpora una CTA con WhatsApp para convertir la consulta en una solicitud de atención rápida y sencilla.
